# ZARA Android App

ZARA's Android shell is built with Capacitor 8. The APK contains the frontend; it connects to a separately hosted ZARA backend.

## Backend requirements

1. Deploy the ZARA backend and frontend/API on a trusted HTTPS host.
2. Use a persistent disk for `ZARA_DATA_DIR`; SQLite data must survive service restarts.
3. Keep both provider API keys in the backend's private environment or supported secure secret storage.
4. Set `NODE_ENV=production`.
5. Set `CORS_ORIGINS=https://localhost` for the Android WebView origin. Add any other exact trusted browser origins as needed.
6. Keep the backend behind HTTPS and a trusted reverse proxy. Do not expose provider service ports.
7. Create the Owner account on the hosted installation before using the app.

The Android WebView uses the app origin `https://localhost` and sends credentialed requests to the configured API host. The backend issues a Secure, HttpOnly, SameSite=None session cookie only for an allowlisted cross-origin request. The generated Android activity enables third-party cookies for this app's WebView so the session can be retained. Only connect to a server you trust.

## First launch on Android

1. Install the APK.
2. Enter the base HTTPS address of your ZARA server, for example `https://zara.example.com`.
3. Create or sign in with the owner password for that server.
4. Chat, history, settings, and provider status use the same protected backend account.

The server address is stored in the app's local configuration. The owner password is not stored by the frontend.

## Build APK

The repository includes a manual GitHub Actions workflow:

- GitHub → Actions → **Build ZARA Android APK** → Run workflow.
- Wait for the workflow to finish.
- Download the `zara-android-debug-apk` artifact from that workflow run.

The workflow installs dependencies, builds the web assets, generates the Capacitor Android project, enables the scoped WebView cookie policy, and builds a debug APK. This workflow has not yet been run, so no APK is claimed to exist.

## Local development

Capacitor requires Node.js 22 or later. The Android platform build also requires Android SDK packages and a compatible Java toolchain. The CI workflow installs Java 21 and the Android SDK automatically. The native Android project is generated by `npx cap add android` and is not currently committed to the repository.

To generate and sync it locally:

```bash
npm install
npm run build:mobile
npm run mobile:prepare
npx cap sync android
```

A local Android build can then be run from the generated `android` directory with its Gradle wrapper.
